# 阳光花园守护计划 🌻

一个基于「植物大战僵尸」玩法的儿童游戏化学习平台。把作业变成"守护花园"的冒险，完成任务击退僵尸，赚取阳光种植植物、兑换现实奖励。

🔗 **在线体验**：https://buptwds.github.io/sunshine-garden/

## 如何部署你自己的版本（3分钟）

### 你需要准备
- 一个 GitHub 账号（免费注册：[github.com](https://github.com)）
- 5 分钟时间

### 第一步：下载代码

点击本仓库右上角绿色的 **Code → Download ZIP**，解压后得到 `index.html`。

或者直接复制 `index.html` 文件内容保存到本地。

### 第二步：创建你的仓库

1. 登录 GitHub，点右上角 **+ → New repository**
2. 仓库名填 `sunshine-garden`（或你喜欢的名字）
3. 选 **Public**（公开，免费）
4. 点 **Create repository**

### 第三步：上传文件

1. 在仓库页面点 **uploading an existing file**
2. 把 `index.html` 拖进去
3. 点 **Commit changes**

### 第四步：开启 GitHub Pages

1. 仓库页面点 **Settings** → 左侧 **Pages**
2. **Branch** 选 `main`，点 **Save**
3. 等 1-2 分钟，页面顶部会显示：
   > Your site is live at `https://你的用户名.github.io/sunshine-garden/`

✅ **部署完成！** 用手机浏览器打开这个链接就能用了。

### 第五步：开启自动备份（可选但推荐）

1. 打开你的页面，切到家长端（默认密码 `1234`）
2. 生成一个 GitHub Token：
   - 打开 https://github.com/settings/tokens
   - 点 **Generate new token (classic)**
   - 勾选 `repo` 权限，有效期选 **No expiration**
   - 复制生成的 Token
3. 在页面"数据备份"卡片中粘贴 Token → 保存
4. 选择备份频率（每天/每周）
5. 之后数据会自动备份到 GitHub，清缓存也不丢

## 常见问题

**Q：清缓存数据会丢吗？**
A：开启了自动云备份就不会。也可以随时手动导出 JSON 文件保存。

**Q：换手机怎么恢复数据？**
A：新手机打开链接 → 家长端 → 点"☁️ 从云端恢复"。

**Q：怎么更新到最新版？**
A：关注原仓库更新，下载新的 `index.html` 替换即可，数据不受影响。

**Q：可以给多个孩子用吗？**
A：目前一个页面一套数据。多个孩子建议各自部署一份。
